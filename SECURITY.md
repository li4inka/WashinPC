# Reporting security problems

This preview performs permanent file deletion and elevated registry changes. The Windows compatibility matrix and adversarial qualification are not complete.

The available contact channel is [GitHub Issues](https://github.com/li4inka/WashinPC/issues). For a sensitive report, open an issue titled **Security contact request**, describing only the affected version and requesting a private contact method. Do not publish exploit details, private paths, registry exports, credentials or personal files. A maintainer can arrange the private follow-up. No private advisory service or response-time guarantee is claimed.

For a non-sensitive safety defect, include expected versus observed behavior and a minimal synthetic reproduction. Do not run destructive reproductions on production data.

## По-русски

Для чувствительного сообщения создайте [обращение](https://github.com/li4inka/WashinPC/issues/new) с заголовком **Security contact request**, версией приложения и просьбой о приватном канале связи. Не публикуйте детали эксплуатации, личные пути, резервные копии реестра или пароли. Срок ответа и наличие приватных advisory не гарантируются.
