# WashinPC — dual targets

This solution now contains two projects:

- **WashinPC** (.NET Framework 4.0, x86) — runs on Windows XP through Windows 11 (requires .NET 4.0 installed).
- **WashinPC47** (.NET Framework 4.7, x86) — runs on Windows Vista SP2 through Windows 11. **Does not run on Windows XP**.

Both projects share the same source files (linked). Build either `Release|x86` configuration for the desired target.

- **WashinPC48** (.NET Framework 4.8, x86) — Windows 7 SP1 → 11. Requires .NET 4.8 Developer Pack for build.
