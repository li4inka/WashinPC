# Руководство пользователя

## Назначение

WashinPC помогает очищать временные файлы, приватные следы и безопасный «мусор» реестра с минимальным риском для ОС.

## Разделы

- Очистка: сканирование и удаление выбранных групп файлов.
- Приватность: сканирование и удаление выбранных следов браузеров/приватности.
- Реестр: сканирование выбранных категорий и консервативное исправление.
- Контекстное меню: управляемые действия отключения/удаления пунктов.
- Настройки: язык и экспертный режим реестра.

## Экспертный режим реестра

По умолчанию действует safe-only. Категории «Продвинутый/Рискованный» видны, но недоступны.
Включение:

1. Откройте `Настройки`.
2. Включите `Экспертный режим реестра`.
3. Вернитесь в `Реестр` и отметьте нужные категории.

## Работа с контекстным меню

1. Откройте `Контекстное меню`.
2. Нажмите `Обновить`.
3. Отметьте элементы в колонках `Откл.` и/или `Удал.`.
4. Нажмите `Применить`.

Примечания:

- Для части записей доступно только отключение или только удаление.
- Неподдерживаемые действия отображаются как disabled с пояснением.

## Замечания по безопасности

- Перед изменением реестра приложение пытается создать точку восстановления.
- При неудаче показывается выбор `Продолжить/Отмена`.
- Авто-фикс ограничен подтвержденными «битыми ссылками», где это возможно.
