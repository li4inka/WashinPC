# Руководство — 1.2.0-preview.2

Запускайте WashinPC от администратора в учётной записи, данные которой хотите обслуживать. Сохранены пять разделов: очистка, приватность, реестр, контекстное меню, настройки.

## Анализ и выбор

Сначала выполните анализ, затем выберите группы. При первом анализе файлы не отмечаются автоматически; Prefetch необязателен. Очистка охватывает временные папки и недавние ярлыки. В приватности доступны отдельные категории истории, cookies и кэша Chrome, Edge, Firefox, Opera, Opera GX, Brave и Яндекс Браузера. Поддерживаются стандартные профили; нестандартные переносимые установки не включены. Закройте браузеры; базы со служебными файлами восстановления SQLite пропускаются.

Обрабатываются только выбранные объекты из сохранённого анализа. Для новых файлов нужен новый анализ. Изменившиеся, занятые, связанные и неподдерживаемые файлы пропускаются. История и cookies очищаются транзакционно внутри баз. Закладки Firefox, пароли, автозаполнение и сессии сохраняются. Очистка cookies приводит к выходу из аккаунтов сайтов. Очистку файлов и корзины отменить после выполнения нельзя. Удалённые файлы, очищенные записи и удалённые байты учитываются отдельно; размер изменённой базы не выдаётся за освобождённое место.

## Итог и отмена

Операции идут в фоне. Кнопка «Отмена» находится под страницей. Запрос обрабатывается между шагами; заблокированный системный вызов или создание точки восстановления сначала должны завершиться. Уже выполненные изменения сохраняются. Итог показывает число выполненных, пропущенных и ошибочных объектов и размер успешно удалённых файлов, а не изменение свободного места тома. «Подробности» группирует причины без личных путей.

При переключении страниц результаты и выбор сохраняются. Одновременные операции запрещены. Закрытие занятого окна запрашивает отмену; после завершения закройте его повторно.

## Реестр

Исправление поддерживается для всех категорий сканирования. Экспертный режим включает дополнительные категории для сканирования и исправления. Перед исправлением приложение проверяет затрагиваемые данные реестра и актуальность находки, затем создаёт проверенную резервную копию. Недоступный или неоднозначный путь не считается отсутствующим.

Перед исправлением предпринимается создание точки восстановления. Если оно не удалось, можно отменить работу; продолжение всё равно требует успешной копии для каждого изменяемого объекта. Отключить резервирование нельзя.

«Службы Windows» — отдельная опасная категория, доступная в экспертном режиме и выключенная по умолчанию. Отключаются только остановленные службы с собственным подтверждённо отсутствующим EXE через диспетчер служб Windows. Драйверы, общие процессы, работающие службы и неоднозначные пути пропускаются. Службы и их файлы не удаляются.

## Контекстное меню

Обновите список. «Откл.» отражает отключённое состояние; измените отметку для отключения/включения. «Удал.» выбирает удаление. Удаление требует подтверждения. Записи перепроверяются и резервируются. Обработанные строки уходят из текущего результата; обновите список для просмотра нового состояния. Блокировку расширения на уровне компьютера пользовательский переключатель не снимает.

## Копии и настройки

«Резервные копии» открывает каталог копий. Выберите копию, нажмите «Сравнить», проверьте изменения, затем «Восстановить» и подтвердите запись. Перед записью сохраняется текущее состояние затрагиваемых объектов. Поддерживаются старые `.reg` и сведения о разрядности из `.reg.txt`; если представление неизвестно, выберите x86/x64. Новые копии содержат версию метаданных, учётную запись и контрольную сумму. Конфигурации служб восстанавливаются через диспетчер служб Windows. «Открыть папку» показывает Документы/WashinPC_Backups/Registry. Для операций контекстного меню может быть несколько отдельных копий: восстанавливайте нужные копии значений вместе с копией ключа. Объекты, не перечисленные в копии, сохраняются, кроме явных директив удаления в обратных копиях. ACL и метаданные ключей не восстанавливаются. Копий очищенных файлов нет.

Настройки остаются в HKCU/Software/WashinPC; старые копии не перемещаются. Язык подписей меняется сразу; сообщения операции используют язык на момент её завершения. Установщик не нужен. При удалении portable-папки сохраните резервные копии отдельно.

В настройках доступны системная, светлая и тёмная темы. Системная следует теме приложений Windows во время работы и сохраняется при повторном открытии настроек. Если системная настройка недоступна, используются светлые цвета.
