# Безопасность реестра

## Область

Документ фиксирует практические гарантии безопасности для операций с реестром на Windows 7/8/10/11.

Абсолютная гарантия «никогда не сломать ОС» недостижима. WashinPC использует консервативные ограничения для снижения риска.

## Контроли безопасности

1. Профиль safe-only по умолчанию.
2. Категории Advanced/Dangerous видимы, но выключены по умолчанию.
3. Попытка создать restore point перед изменениями.
4. Диалог continue/cancel при неудаче restore point.
5. Опциональный backup ключей перед фиксом.
6. Итоги сессии: fixed/failed/skipped.

## Pipeline фикса

1. Preflight выбранных проблем.
2. Попытка создания restore point.
3. При fail — подтверждение continue/cancel.
4. Выполнение фиксов с явным контекстом.
5. Формирование итогов и логов.

## Правило авто-фикса

Авто-исправление должно применяться только к подтвержденным «битым ссылкам» (отсутствует файл/путь).
Эвристические и неоднозначные кейсы по умолчанию пропускаются.

## Восстановление

- Откат через System Restore (если точка создана).
- Откат через экспортированные backup `.reg` (если включено).
- Повторный скан после применения обязателен для валидации результата.
