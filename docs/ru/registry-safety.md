# Безопасность реестра

Исправление доступно для всех категорий сканирования через соответствующие обработчики. Экспертный режим открывает дополнительные категории для сканирования и исправления. Для исправления необходимы доступный снимок и проверенная резервная копия. Отсутствие подтверждается только при доступном непосредственном родительском каталоге; ошибки доступа, отсутствующий родитель, сетевые и относительные пути считаются неопределёнными.

Для доступной к исправлению находки сохраняется снимок затрагиваемых значений или всей изменяемой ветки. Независимые исправления значений в одном ключе могут применяться вместе. Перед изменением приложение проверяет снимок и актуальность находки, создаёт уникальный UTF-16 `.reg` с исходными типами значений, проверяет записанный файл и ещё раз проверяет объект. Неудача блокирует изменение. Это не транзакционный движок реестра: параллельная запись может произойти после последней проверки. Для квалификации нужен спокойный тестовый стенд.

Сопутствующий файл содержит исходную ветку, ключ, представление x86/x64 и команду импорта. Ручной импорт может перезаписать более новые значения, не восстанавливает ACL и не является восстановлением с проверкой конфликтов. Для переключателей контекстного меню создаются копии значений с директивами удаления тех значений, которые первоначально отсутствовали. Удаление расширения не очищает общие списки блокировок.

Перед исправлением реестра предпринимается создание точки восстановления. При неудаче требуется «Продолжить/Отмена»; продолжение не отключает обязательную копию. Старые копии остаются на месте. Фактическая квалификация ОС указана в [результатах](../validation/README.md).

Встроенный каталог копий показывает сравнение, проверяет контрольную сумму и учётную запись, сохраняет текущее состояние затрагиваемых объектов и повторно сверяет его перед восстановлением. Новые копии содержат версионированные JSON-метаданные; для старых используется файл со сведениями о представлении реестра или явный выбор x86/x64. Восстанавливаются только перечисленные объекты. Операция не атомарна; частичные ошибки отражаются в результате. Копии служб восстанавливают тип запуска через диспетчер служб Windows, без прямой записи `Start`. Категория служб доступна только в экспертном режиме, выключена по умолчанию и ограничена остановленными службами с собственным однозначным отсутствующим EXE.
