# Безопасность реестра

Preview исправляет только отсутствующие SharedDLL с нулевым счётчиком и отсутствующие HelpFile. Остальные категории диагностические, включая экспертный режим. Отсутствие подтверждается только при доступном непосредственном родительском каталоге; ошибки доступа, отсутствующий родитель, сетевые и относительные пути считаются неопределёнными.

Для доступной к исправлению находки сохраняется снимок ключа. Перед изменением приложение проверяет снимок и отсутствие цели, создаёт уникальный UTF-16 `.reg` с исходными типами значений, проверяет записанный файл и ещё раз проверяет объект. Неудача блокирует изменение. Это не транзакционный движок реестра: параллельная запись может произойти после последней проверки. Для квалификации нужен спокойный тестовый стенд.

Сопутствующий файл содержит исходную ветку, ключ, представление x86/x64 и команду импорта. Ручной импорт может перезаписать более новые значения, не восстанавливает ACL и не является восстановлением с проверкой конфликтов. Для переключателей контекстного меню создаются копии значений с директивами удаления тех значений, которые первоначально отсутствовали. Удаление расширения не очищает общие списки блокировок.

Перед исправлением реестра предпринимается создание точки восстановления. При неудаче требуется «Продолжить/Отмена»; продолжение не отключает обязательную копию. Старые копии остаются на месте. Фактическая квалификация ОС указана в [результатах](../validation/README.md).
