# Диагностика и QA-матрица

## Типовые проблемы

### Требуются права администратора

Симптом: приложение закрывается при старте.
Действие: запуск от имени администратора.

### Не создана точка восстановления

Симптом: предупреждение перед фиксом реестра.
Действие: для максимальной безопасности выбрать `Отмена`; `Продолжить` — только при осознанном риске.

### Отказ в доступе при применении

Симптом: частичный успех и счетчики skipped/failed.
Действие: повторить с elevation, проверить политики безопасности/антивирус.

## Ручная QA-матрица

Для восстановления нужна доступная поддерживаемая копия; если в старой копии неизвестна разрядность, выберите её явно. При изменении объекта повторите сравнение. Privacy сохраняет базы с неподдерживаемой структурой и базы работающего браузера. Интеграционный тест изменения временной службы требует повышенных прав Windows; разрешение на выход из песочницы само по себе не предоставляет токен администратора Windows.

## Release Gate

Релиз-кандидат получает `PASS`, только если:

1. Автотесты зеленые.
2. В QA-матрице нет блокеров P0/P1.
3. Выполнены требования logging policy.

Иначе: `FAIL`.


Локальные проверки и ограничения: [результаты](../validation/README.md). Ошибка копирования блокирует изменение; исправление поддерживается для всех категорий сканирования с проверкой снимка и актуальности находки.
